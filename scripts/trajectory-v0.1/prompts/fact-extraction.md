# 原子事实抽取提示词 · v0.1（trajectory-v0.1）

- 版本：fact-extraction v0.1（2026-10-02，Damn4lee）
- 用途：从「已登记来源的原文片段」抽取原子事实草稿。**输出是草稿，必须经人工核对原文后**，经 `scripts/trajectory-v0.1/import-facts.mjs`（或手工）进入卡片 `facts`。
- 模型接入：若接在线抽取，**复用仓库网关配置**（`server/` 现有 TOKENDANCE 网关参数与 `.env`，不在此硬编码 key、不另建网关实现）。无密钥时本流程完全离线可用：人工摘录原文片段 → 按本模板手工填事实 → `import-facts.mjs` 校验导入。

## 输入（每次一个片段）

```
人物：{person_id}（{姓名}）
来源：{source_id}（题名/作者/版本；来自 data/trajectory-v0.1/sources.json 登记条目）
定位：{locator —— 章节/页码/段落；搜索页与来源标题不能作为定位}
原文片段：
"""
{粘贴原文，不整本投喂}
"""
已知时间锚：{该片段内出现的事件年份表，供对齐}
```

## 输出（JSON 数组，每条一个原子事实）

```json
[
  {
    "text": "单句、单一主张、可独立核查",
    "occurred": { "start_year": 1906, "end_year": 1906 },
    "kind": "fact | inference | retrospective",
    "confidence": "high | medium | low",
    "source_refs": [{ "source_id": "…", "locator": "…" }],
    "notes": "争议/同源说明/不确定性"
  }
]
```

## 纪律（违反任何一条 = 该条作废）

1. **原子性**：一条一个主张。「退学并赴上海」拆成两条。复合句先拆再抽。
2. **时间区间**：`occurred` 尽量精确；只有年份就 start=end=该年；区间未知填 null 并在 notes 说明——**不得拿资料出版年冒充事件年**。
3. **定位绑定**：每条必须绑定 `{source_id, locator}`；locator 来自输入片段的实际位置。整本书/搜索页不是定位。
4. **kind 判定**：
   - `fact`：客观发生（含后世传记对早年客观事实的记载——出版晚不是排除理由）。
   - `retrospective`：人物**后来**对自己动机/经历的解释（自序、回忆录中的归因）。**禁止进入决策前视图**，只用于结果/反思层。
   - `inference`：抽取者的建模判断。默认分档判断（low/medium/high）都是 inference。
5. **不脑补**：原文没有的经济状况、家庭关系、心理动机一律不输出；不知道就不知道。
6. **冲突保留**：两个来源矛盾时输出两条并在 notes 标注争议，不强行统一。
7. **同源警惕**：转载/引用同一原始出处的不算独立交叉验证；notes 里注明。
8. **未来不进过去**：奖项、成败、声望只能作为「事件后」事实抽取，并标注发生年份。

## 人工核对清单（进卡片前逐条过）

- [ ] 对照原文逐字核对 text 与 occurred
- [ ] locator 精确到能重新找到原文
- [ ] kind 判定复核（特别是把 retrospective 误标成 fact 的）
- [ ] 与卡内既有事实查重（同文跳过，冲突标争议）
- [ ] 通过 `import-facts.mjs` 结构校验后，由人决定并入哪张卡
