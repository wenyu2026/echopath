# EchoPath · 来路 —— 完整版（2026-10-03）

让前人的来路，成为后来者看向未来的回响。

一个「人生决策参考」产品：AI 访谈把用户处境讲清楚 → 在真实人物/校友数据里找出**结构相似的人**，看他们实际走了哪些路 → 深读真实案例（严格区分「当时知道」和「后来发生」，逐人说明"为什么给你看他"）→ 回到自己，形成一份可撤回的下一步验证计划。

---

## 快速开始（Windows，两步）

**前提：装 Node.js 24**（或 ≥ 23.6）。没装的话去 https://nodejs.org 下 LTS 版，一路下一步即可。
（不需要 npm install —— 这个项目运行时零第三方依赖。）

1. 解压后，双击 **`backend\start-backend.bat`** —— 出现「Starting … on http://localhost:3100」后**不要关这个黑窗口**
2. 双击 **`frontend\start-frontend.bat`** —— 会自动打开浏览器 http://localhost:7200/

想停掉：把两个黑窗口关掉（或按 Ctrl+C）。

### Mac / Linux

```bash
cd backend  && PORT=3100 node --env-file=.env server/api.ts     # 窗口一
cd frontend && ECHOPATH_API=http://localhost:3100 node server.mjs --port 7200   # 窗口二
```

## 🔑 关于 AI Key（重要，请读）

- `backend\.env` 里已经填好一条**可用的 TokenDance Key**，解压即可完整体验（访谈等 AI 功能全部可用）。
  **注意：AI 调用消耗的是这条 Key 的额度**——玩得省一点，跑挂了就是额度用尽了。
- 不想用/想换成自己的：用记事本打开 `backend\.env`，把 `TOKENDANCE_API_KEY=` 那行改成你自己的 Key（在 https://tokendance.space/keys 创建）或直接清空，然后重启后端。
- **清空 Key 也能跑**：访谈会提示"未配 Key"，但「后端连接设置 → 用示例处境看决策地形 → 案例深读」这条完整链路不需要 Key，可以体验除访谈外的全部页面。

## 里面有什么

| 目录 | 是什么 |
|---|---|
| `backend/` | 后端（Node/TypeScript，零运行时依赖）：访谈引擎（带追问纪律）、决策地形 v2（人找人 → 因素聚类）、案例深读、动态回忆入口；数据 = 36 条历史人物 + 20 条脱敏校友 |
| `frontend/` | 六页产品界面（纯 HTML/CSS/JS，零依赖）：首页回响+提灯旅伴 / 来时路（访谈+来路图）/ 理解困境 / 决策地形（知识网络）/ 真实案例（四区块深读）/ 回到自己（行动记录）；含 API 调试台、导出导入 |
| `design-docs/` | 设计共识、逐轮交接记录（含给后端工程师的字段需求清单） |

### 产品能力（本版）
- **访谈引导**：说"迷茫/不适合"会被追问到具体的事（不跳话题）；说"不知道"会降难度给回忆入口、可跳过；一次讲多件事一轮抽全、不重复问；说错可纠正；「帮我回忆」按你的语境动态出题
- **来路图**：主路径只放经历与转折，约束/目标/担忧是旁注；点节点看自己的原话、就地纠正；未定的未来画成空心问号
- **决策地形**：每条分支都标明来历（"匹配到 N 位和你根因素相近的人，其中 M 位走了这条"）；悬停预览/点击固定选中/键盘可达
- **真实案例**：每个人名下标注「与你的共同因素」；详情页逐人回答"为什么给你看他 / 你俩像在哪 / 不像在哪（不能照搬）/ 可以借鉴什么 / 还有什么不知道"；时间边界、证据分层、来源可展开
- **回到自己**：四步行动记录（回看→取舍→未知→可编辑行动卡），保存到浏览器本地、刷新不丢
- **分享**：便签底部「导出记录」把整次探索存成 JSON 发给别人，对方「导入」即可看到你的完整来路

## 常见问题

| 现象 | 处理 |
|---|---|
| 端口被占用（EADDRINUSE） | 换端口：改两个 bat 里和 README 命令里的 3100/7200 为别的数字（两处要一致） |
| 浏览器能开但访谈说"没配 Key" | `backend\.env` 的 Key 被清空或失效了，填一条新 Key 重启后端 |
| 访谈提示"AI 额度用完了（网关返回 HTTP 402）" | Key 额度耗尽，换 Key 或充值 |
| 页面打不开 http://localhost:7200 | 前端的黑窗口还开着吗？先开后端再开前端 |
| Node 版本报错 | 装 Node 24：https://nodejs.org |

## 接口一览

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | 存活 + Key 配置状态 |
| POST | `/api/interview/start` · `answer` · `finish` | 无状态访谈；`answer` 带 `mode`（追问/救援）与 `hints` |
| POST | `/api/interview/hints` | 「帮我回忆」动态入口 |
| GET | `/api/sources` | 数据源列表 |
| POST | `/api/landscape` | 决策地形（含每条分支的聚类来历、每条案例的因素标注） |
| POST | `/api/case` | 案例深读（含该案例的因素标注 mechanism，供页面回答"为什么给他看"） |
