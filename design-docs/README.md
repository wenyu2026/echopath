# EchoPath 迁移包（2026-10-03）

用途：换电脑 / 换协作者时，直接拷这个文件夹或 `.zip`，内容自足，不需要安装任何环境。

## 包内结构

| 文件 / 目录 | 是什么 |
|---|---|
| `01_设计上下文与灵感.md` | 从团队分享对话提取的完整设计共识（总方向、色彩、材质、排版、线点分叉、六页结构、内容原则） |
| `02_UI控制台与构想案例.md` | 你的定制 Markdown：视觉操控台、页面案例、协作口令、元素需求卡（8 问）、范式验证 |
| `03_UI_Demo/` | 初版 UI Demo：HTML / CSS / JS，纯本地运行 |
| `03_UI_Demo/BACKEND.md` | 后端接入说明：六页与真实接口对照、降级规则 |
| `03_UI_Demo/smoke-test.mjs` | 全链路冒烟测试（真实 LLM，9 项验收），用法见文件头 |
| `04_交接记录_2026-10-03.md` | 本轮交接记录：状态、验收证据、端口占用现状、接手第一步 |

## 怎么打开 Demo

双击 `03_UI_Demo/index.html` 即可（Chrome / Edge / Safari 都行），不需要服务器、不需要联网。

六个页面都能点：首页 / 来时路 / 理解困境 / 决策地形 / 真实案例 / 回到自己。
左侧目录可以悬停预览、点击切页，右上角「«」可以收成一条垂直标签再拉出来。

## 怎么跑真实链路（后端 + 真实模型）

1. 起后端：`cd xuejun-hackathon`，`npm run server`（需要 `.env` 里配好 `TOKENDANCE_API_KEY`；注意本机 3000 被 new-api 占用，用 `set "PORT=3100" && npm run server`）；
2. 起前端预览：在本目录 `node server.mjs --port 7200`（`ECHOPATH_API=http://localhost:3100` 指到后端）；
3. 浏览器开 `http://localhost:7200/`，从「02 来时路」开始访谈；
4. 快速验收：`node smoke-test.mjs`（9 项全链路检查，详见 `04_交接记录_2026-10-03.md`）。

说明：

- 浏览器不再直连大模型——访谈抽取在后端做，更可靠；Key 只放后端 `.env`，本包内不含任何密钥；
- 后端连不上时 Demo 自动降级为模拟模式，六页仍可浏览。

## 迁移到新电脑后如何继续协作

1. 把 `01_设计上下文与灵感.md` 和 `02_UI控制台与构想案例.md` 一起发给新的 AI/协作者；
2. 告诉它：先读这两份，再按 `03_UI_Demo` 现状改；
3. 提需求时沿用约定的说法：
   - **加元素** → 元素需求卡 1–6 问（叫什么 / 放哪 / 里面有什么 / 用户能做什么 / 何时出现 / 多重要）；
   - **改交互或质感** → 补第 7–8 问（怎么触发 / 不能破坏什么）；
   - **改内容规则** → 单独写一条，不和 UI 混在一起。
