# EchoPath · 来路 —— 设计上下文与灵感（完整版）

> 来源：团队 ChatGPT 分享对话的提取整理
> 原始链接：https://chatgpt.com/share/6abf6939-bd10-83ee-8473-503a57f33653
> 用途：迁移到新电脑 / 交给新协作者时，先读这份，能快速回到我们当前的设计共识。

---

# 一、总方向（一句话）

**「自然静谧 × 编辑式极简 × 柔和数字质感」**

大白话：

> 做一个安静、有自然温度、适合认真阅读和思考的现代界面；排版像一本认真设计过的现代刊物；再用少量 Apple 式"果冻感"，让 AI 和交互显得有生命。

明确排除的方向：

- 不做古风；
- 不做赛博蓝紫 / 科技炫技；
- 不做普通 AI SaaS 后台；
- 不堆圆角卡片；
- 不做满屏玻璃拟态。

---

# 二、核心视觉元素

## 1. 色彩

- 来源：自然界树木、原木、植物、奶油白、暖灰。
- 主基调：**原木绿 / 植物绿 / 灰橄榄绿** + **暖米白**。
- 强调色：**木橙 / 蜂蜜棕 / 焦糖橙**，只用于关键决策、当前节点、代价提醒。
- 正文：石墨黑、深灰，不用纯黑。
- 建议比例：暖白约 75–80%，原木绿约 15%，木橙约 5%，黑灰约 5%。
- 灰蓝可保留为极少量中性色 / 理性色，不做品牌主色。
- 明确态度：**去掉单独色卡，保留"原木特性"**。

## 2. 材质 / 质感

- "果冻质感"是团队内部的暗号，实质是 **Apple-like 材质语言**：
  半透明、软边、轻微模糊、层次细腻、动效顺滑，但很克制。
- 使用规则：**只用于导航、当前状态、AI 动态、关键交互。**
- 不是装饰，而是"状态语言"：告诉用户"这里是活的，这里正在发生变化"。
- 目标：让它成为产品记忆点，像 7-Eleven 的三个颜色一样，一看就联想到我们。

## 3. 排版

- 核心：**编辑式极简 / 编辑式阅读排版**，不是时尚杂志风。
- 按人的阅读顺序组织，而不是按功能模块堆卡片：
  原来走什么路 → 发生了什么 → 站在哪个路口 → 当时知道什么 / 不知道什么 → 做了什么 → 后来如何。
- 工具：大留白、清晰字号层级、短段落、细线分隔、小标题、适量图片。
- 原则：**不是所有信息都需要一个容器。**
  - 页面内容：可以完全无卡片；
  - 可点击案例：轻微圆角 + 极浅边框；
  - AI 当前状态：果冻玻璃；
  - 重大决策：原木绿 / 木橙强调。
- 极简 ≠ 内容少，而是 **没有不必要的东西**。
- 正文宽度、字号、栏宽等具体参数：暂缓，等视觉稿出来靠眼睛调。

## 4. 布局 / 导航

- 倾向：**纵向目录栏 + 果冻质感**，而不是底部横向 Tab。
- 人物列表：参考高质量通讯录 / 档案列表，人像 + 简约简介，但比通讯录多一点文字；点进去看完整来路。
- 纵向导航当时未完全敲定，保留争议；横纵关系与视觉质感等 demo 出来后再定。

## 5. 视觉层级

> **文字是第一视觉层；图片 / 人物 / 案例是第二视觉层；线点分叉是第三视觉层。**

- 每个页面至少需要一个"视觉锚点"：人物肖像、真实材料、轻渐变、果冻导航、局部照片、动态节点、大数字 / 年份、有设计感的短句、自然色块。
- 否则只有暖白底 + 文字 + 细线，会枯燥。
- 装饰尽量接近零。
- 整体节奏：**平时安静，关键时刻有生命感。**
  80% 的页面克制，只有当 AI 理解出重要因素、生成路径、找到案例、出现人生分叉时，才有动态。

# 三、核心视觉母题：线 + 点 + 分叉

- 它不是 Logo，而是 **Signature Visual System（品牌视觉母题）**。
- 表达：过去经验、人生阶段、决策点、生命轨迹。
- 三个强度：
  - **Level 1**：几乎不可感知。首页背景、普通阅读页，可能只有一条淡曲线、一个节点、一个不完整分叉。
  - **Level 2**：辅助信息。来时路、人物生平、当前阶段，能看出"这是时间 / 人生路径"，但不是主角。
  - **Level 3**：真正成为主体。只在"决策地形页"出现，从当前节点分叉出 2–4 条路。
- 不是每页都画满，不能和文字抢注意力。
- 不一定是直线，可以用轻弧线、柔和转折、有机曲线，甚至可以只有点、不画线。
- 目标：像"生命轨迹"，不是"流程图"。

# 四、页面信息架构：六页一条完整流程

> 进入 → 讲清自己怎么走到这里 → 讲清为什么卡住 → 看见几种真实走法 → 进入真实人生 → 回到自己。

| 页面 | 作用 | UI 重点 |
|---|---|---|
| 01 首页 | 让用户愿意开始 | 安静、大留白；两句品牌文案 + 开始按钮；淡淡路径意象；文字绝对主角；线点分叉 Level 1 |
| 02 来时路 | AI 先认识这个人 | 聊天为主；AI 像很会聊的人，慢慢把经历抽出来；后来升级为"聊天 + 人生轨迹便签"双层结构 |
| 03 理解困境 | 把表面问题往下挖 | 更聚焦的对话；最后形成"我理解到的问题其实是……"；文字为主，线点分叉极少 |
| 04 决策地形 | 展示个性化选择路径 | **线点分叉真正成为主体**；2–4 条路径；每条讲保护什么、代价是什么、相似的人后来发生了什么 |
| 05 真实案例 | 让用户走进一个真实人生 | 人物肖像 + 编辑式深阅读 + 时间线；不要"生于……相似度 82%"的卡片 |
| 06 回到自己 | 把镜头拉回用户 | 页面重新安静；别人的路径退掉；问哪种代价最不能接受、还缺什么、下一步做什么 |

视觉节奏：

> 首页空 → 来时路慢慢进入 → 困境收紧 → 决策地形展开 → 人物故事深入 → 回到自己再次安静。

# 五、文案与内容原则

- 首页主文案：
  **EchoPath · 来路**
  **"让前人的来路，成为后来者看向未来的回响。"**
- 副文案：
  **"不是预测你的未来，而是让你看见别人已经走过的未来。"**
- 主按钮：
  **"开始梳理我的来时路 →"**
- 内容要有文学性、共情，像老师讲一个生动的故事，不能冷冰冰。
- 但史实不能编，原则是：**准确史实 + 文学化叙事 + 明确证据边界**
  （Evidence-grounded Narrative / 有证据的叙事化表达）。

# 六、产品层面的设计约束

- 不做成只服务历史模块的"古风产品"，而是一个**可替换数据库的通用流程**：换成企业数据库也能跑。
- 核心流程必须保留：了解来处 → 深入理解困境 → 生成个性化路径 → 查看具体案例 → 回到自己。
- 这不是效率工具，也不是娱乐产品，而是需要用户**停下来阅读、思考、回看自己**的产品。
- 因此视觉不能太刺激，不能娱乐化，也不能像普通 AI 工具。

---

# 七、已接受 / 保留 / 暂缓

**已接受：**

- 原木色彩方向；
- 把"苹果风"纠正为"借 Apple 的材质语言"；
- 真实图像、简洁图像表达；
- 果冻质感只做点睛；
- 卡片分等级、少用容器；
- 文字为主，减少视觉元素抢戏。

**保留争议 / 待视觉验证：**

- 纵向导航是否最终采用；
- 具体尺寸、字号、栏宽等参数；
- 线稿与文字会不会打架；
- 横纵关系与视觉质感；
- 记忆点最终如何落地。

**工作方法：**

- 先逐页做"语言层统一"，再生成视觉；
- 每页固定讨论六件事：解决什么问题、用户已知什么、最重要一句话、信息一二三级、交互与按钮、允许出现多少路径 / 果冻 / 图片 / 卡片；
- 参考图作为第一批视觉基准，避免设计漂回"普通 AI SaaS"。

---

# 八、收束成一句

> 以文字和阅读体验为主体，用原木绿与暖木色建立安静的自然温度，用编辑式排版建立阅读节奏，用"线 + 点 + 分叉"表达人生路径，用极少量的 Apple 式果冻质感表达 AI 的活性；整体不是历史 App，也不是 AI 工具，而是一个让人愿意停下来认真想一会儿的"来路"界面。
