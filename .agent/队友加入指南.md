# 给你的 GitHub 账号（3 位队友照着做）

> 队长已经把仓库建好了，你要用自己的 GitHub 账号加入协作。
> **全程大约 5 分钟。**

---

## 第 1 步：注册 GitHub 账号

打开 → **https://github.com/signup**

- 邮箱、密码、用户名自己填
- **用户名（username）想好再填** —— 这个要报给队长，用来加你进仓库
- 建议用英文，比如 `zhangwei2026`

> ⚠️ 如果你已经有 GitHub 账号，**直接跳到第 3 步**，不用重新注册。

---

## 第 2 步：验证邮箱

GitHub 会发一封验证邮件，**点里面的链接**。
不验证的话，后面可能会有限制。

---

## 第 3 步：把用户名报给队长

**把你在第 1 步填的用户名发给队长**（比如 `zhangwei2026`），让他邀请你进仓库。

> ⚠️ 注意是 **用户名**，不是你填的昵称，也不是邮箱。
> 用户名在网页右上角头像旁边能直接看到。

---

## 第 4 步：接受邀请

队长邀请你之后，会有两种方式收到：

**方式 1：邮箱里点接受**
GitHub 会给你发一封邀请邮件，里面有 **View invitation** 按钮，点进去接受。

**方式 2：网页上接受**
打开 → **https://github.com/notifications**
或在浏览器直接访问：
```
https://github.com/wenyu2026/xuejun-hackathon/invitations
```

**点绿色的 `Accept invitation` 按钮。**

---

## 第 5 步：验证你进去了

打开队长给你的仓库地址（把 `你的用户名` 换成你自己的）：

```
https://github.com/wenyu2026/xuejun-hackathon
```

**能看到代码 = 成功了。** 看不到就说明邀请还没接受，回第 4 步。

---

## 第 6 步：装 git 并配置你的名字

装好 Git 之后，**在你自己的电脑上**执行这两条（把用户名和邮箱换成你的）：

```bash
git config --global user.name "你的GitHub用户名"
git config --global user.email "你注册GitHub用的邮箱"
```

> 这一步是为了让提交记录能正确算到**你**头上。

---

## 第 7 步：把代码下载到本地

```bash
git clone https://github.com/wenyu2026/xuejun-hackathon.git
cd xuejun-hackathon
```

---

## 第 8 步：告诉你的 AI 助手开始工作

把下面这段**整段复制**给你的 AI（Claude / Codex / Gemini 都可以）：

```
你要加入一个 4 人黑客松团队，协作通过 GitHub 进行。

【先读规则】
完整读一遍仓库根目录的 AGENTS.md，那是全队唯一事实来源。
读完后，去我被分配的 Issue 里发 CHECKIN。

【硬规则】
1. 不许直接 push main，用分支 <你的GitHub用户名>/<简述>
2. 不许自己 merge PR，必须由人类决定
3. 不许提交 package-lock.json
4. 说"完成"之前，必须先跑：
      gh issue list --label "agent:blocked" --state open
      gh issue list --search "mentions:@me" --state open
5. 改别人责任区之前，先在 Issue 发 CHANGE_REQUEST 并等待 OK
6. 不许提交 .env 或任何密钥

【工作方式】
- 每完成一个阶段就在 Issue 里发对应格式的消息，不要闷头做完才说
- 卡住了立刻发 BLOCKED，写清"等谁/等什么/我还能做什么"
- 不确定的事先问我，不要自己猜着改架构

现在开始：先读 AGENTS.md，然后告诉我你读到了什么、你要做什么。
```

---

## 遇到问题？

| 现象 | 原因 | 解决 |
|---|---|---|
| 打不开 github.com | 系统代理没开 | 打开 Clash Verge 的「系统代理」开关 |
| 看不到仓库 | 邀请没接受 | 回第 4 步点 Accept |
| `git clone` 卡住/超时 | 代理没生效 | 先确认 Clash 在跑，再重试 |
| 说仓库不存在 | 用错账号登录了 | 确认登录的是**你自己**刚注册的账号 |

---

## ⚠️ 最重要的一条

**每个人必须用自己的账号。**
不要几个人共用一个账号 —— 那样分不清谁做了什么，而且违反 GitHub 规则。
