## ⚠️ 本区额外职责：根文件与锁文件

member-d 是**根文件的唯一 owner**，也是**锁文件的唯一产者**。

| 文件 | 我的职责 |
|---|---|
| `package-lock.json` | **只有我能提交**。定期跑 `npm install --package-lock-only` 并提交 |
| `vite.config.ts` / `tsconfig.json` | 唯一 owner |
| `src/main.tsx` | 与其他成员协商，同一时间只许一人改 |
| `package.json` | 别人改依赖时我会在 PR 里看到，负责最终一致性 |

**为什么锁文件要单产者：**
> 锁文件是机器生成的，几百行 diff 人眼看不出对错。多方各生成一份 → 必然冲突 →
> 强行 merge → 玄学 bug。集中到一个产者是从根上解决。

**发现别人 PR 里带了 `package-lock.json` → 直接打回。**
