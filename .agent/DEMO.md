# Demo 剧本（可执行版）

> 目标：让评委在 **90 秒内**看懂「这不是 ChatGPT + 历史人物壳」。
> 本文是**操作手册**：照着做就能跑完一遍，不需要临场想词。
> 最后更新：2026-10-02（T5 集成完成）

---

## 零、开始前 5 分钟检查（逐项打勾）

```
□ 一条命令能起来：        npm start
□ 打开 http://localhost:5173 看到「来路 EchoPath」
□ 顶部不出现黄色「离线演示模式」横幅     ← 出现说明后端没通，见下方排错
□ server/api.ts 起来了（终端里有「案例索引就绪：36 条」）
□ 浏览器缩放 100%，字体大小默认
```

**排错：**

| 现象 | 原因 | 处理 |
|---|---|---|
| 黄色「离线演示模式」横幅 | 后端没通 | `npm run server` 单起后端，看报错 |
| 终端刷 `batch size is invalid` | embedding 批量超 20 条 | 检查 `server/embedding/embed.ts` 的分批逻辑 |
| 页面空白 | 前端没起来 | `npm run dev` |
| 接口很慢（20s+） | Clash 把 TokenDance 也代理了 | TokenDance **不该走代理**，见 AGENTS.md 第 9 节 |

> **即使后端完全挂掉也能演示** —— 前端会自动降级到打包好的快照（`src/data/demoCache.ts`），
> 流程照样走得完。这就是为什么要有兜底。

## 一、90 秒逐拍脚本

### ① 0–10s｜开场（站在 P1 页面）

**说：**
> 这是每个大学生都可能遇到的一刻：学了两年，越来越觉得不适合自己。

### ② 10–25s｜输入（P1）

在第一个输入框打字（**不要念稿，真的打字**）：

```
大三，专业是材料科学，已经读了两年半
```

其余五问**直接点「下一个问题 →」跳过**。

**说：**
> 它没有立刻给建议 —— 而是先问清处境，再去找人。

### ③ 25–40s｜当前路口卡（P2）

停 2 秒让大家看清抽出来的结构，然后**现场改一个字段**：
- 点「现实约束」里的任一标签 → 改文字 → 回车
- 或点 `×` 删一条、点「+ 添加」加一条

**说：**
> 这是它从我的话里抽出来的结构。**不对的地方我可以直接改** ——
> 我的处境由我定义，不是由系统定义。

### ④ 40–55s｜人生分叉地图（P3）

点「看看别人从这里去了哪里 →」

**先指检索过程条：**
> 全部案例库 → 语义召回 **36 条** → 约束筛选 → 结构重排 → 多样性采样 **3 条**。
> 匹配靠的是结构相似（阶段 / 困境 / 约束 / 目标 / 可逆性），**不是文本相似**。

**再指地图：**
> 它不给我一条路，给我**三条真实有人走过的路**。
> 注意这三条覆盖了**不同的选择方向** —— 不是最像的三个。

### ⑤ 55–70s｜案例详情（P4）

点任一条路径卡 → 「看这条路的完整经过」

**快速滚过**：当时处境 → 有哪些选项 → 实际做了什么 → 短/中/长期结果 → 他后来怎么反思

**点右上「🔍 看证据来源」** 打开抽屉：
> 每个关键事实都能点开看来源。这里还标了哪些是**后人解释**、哪些是 **AI 推断**。

### ⑥ 70–85s｜像与不像（P5）★ **最关键的一屏**

点「对比『像与不像』→」

**先指左边「像你的地方」，再指右边「你不能照搬的地方」：**

> 这是整个东西最要紧的部分。
> 它会主动告诉我 —— **为什么我不能照搬**。

**指着黄色徽章说：**
> 标「⚠️ AI 类比」的是模型的外部知识推断，**不是史实**；
> 标「未知」的是案例资料里查不到、它不替我猜的部分。

> 注意这句：「案例记录中没有这部分内容，**无法确认**对方当时是否面对同样约束」——
> 它没有说「对方没有」。**查不到 ≠ 事实上没有**，它承认自己不知道。

### ⑦ 85–90s｜收尾（P6）

点「这些和我有什么关系？→」→ 选一个「最不能接受的结果」→ 点「完成」

**念收尾句：**

> **历史没有替你做选择，但现在你已经知道：哪些路真的有人走过，它们分别付出了什么。**

## 二、三个必须现场演示的「技术证明」

光讲没用，**要让评委看见**。

### 证明 1：检索过程可视化（P3 顶部）

```
全部案例库 → 语义召回 36 条 → 约束筛选 32 条 → 结构重排 3 条 → 多样性采样 3 条
耗时 0.9s
```

**说**：我们没有隐藏过程。这四步里的每一步都可以追问。

### 证明 2：维度卡（P5）

7 个维度的进度条，代替「相似度 87%」。

**说**：为什么不做单一分数？因为**单一分数不可解释** ——
你没法知道它为什么像、哪里不像。维度卡自己就引出了下一屏。

### 证明 3：证据分层（P4 底部）

五层：**史实 / 本人表述 / 后人解释 / AI 类比 / 未知**

**说**：最后一层是我们主动加的。**不确定的东西标出来，比编一个强。**

## 三、必须现场说的三句话（防质疑）

| 评委可能问 | 你回答 |
|---|---|
| 「这不就是 ChatGPT 吗？」 | 「ChatGPT 检索的是**知识**，我们检索的是**决策事件**。而且它会主动告诉你**为什么不能照搬** —— 聊天机器人不会做这件事。」 |
| 「历史人物和现在不一样，参考价值在哪？」 | 「**这正是我们的核心机制。** 我们不假装可比，而是强制输出差异维度。你看那个黄色徽章 —— 时代差异是**单独标注**的。」 |
| 「这有商业价值吗？低频吧？」 | 「**对，我们不假装它高频。** C 端重大决策天然低频。真正的场景是高校生涯教育 —— 把案例库变成课堂工具。这既高频复用，又扣住 Echo 赛题。」 |

## 四、Pitch 骨架（3–5 分钟）

```
1. 痛点（30s）
   语言很压缩，经验很昂贵。
   很多大道理需要阅历才能解压。

2. 洞察（30s）
   迷茫的人不缺建议，缺的是「和我像的人后来怎么样了」。
   但经验散落在传记、书信、访谈里 —— 不可检索、不可比较、不可代入。

3. 机制（60s）
   检索单位是「决策事件」，不是「人物」。
   结构化匹配 7 个维度，不是文本相似。
   强制反类比 + 证据分层 + 多分叉。

4. Demo（90s）
   走一遍上面的脚本。

5. 技术（30s）
   36 条人工校验的 Decision Episode；7 维度结构匹配；
   证据可追溯到 source_id；AI 推断显式标注。
   实测：结构化 2.5s + 检索 0.3s。

6. 价值与主题（30s）
   商业：高校生涯教育 + 经验 API
   主题：教育不该只告诉后来者「应该怎么做」，
        而应该让他们看见前人真的怎样做过、付出了什么代价。
```

**一句话定位（背下来）：**

> **不是预测你的未来，而是把别人已经走过的未来提前给你看。**

## 六、如果时间不够（降级方案）

**保留**（缺了就不成立）：
1. 处境结构化（P1→P2）
2. 3 个案例 + 多分叉（P3）
3. **反类比**（P5 的「你不能照搬的地方」）
4. 分叉地图

**可以砍**：
- P4 的完整时间轴（只点证据抽屉）
- P6 的反思问题（直接念收尾句）
- 检索过程条

**绝对不能砍反类比** —— 那是这个产品区别于聊天机器人的**唯一铁证**。
