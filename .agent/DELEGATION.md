## 通用前置（所有角色都要先做）

```bash
# 1. 克隆（私有仓库）
git clone git@github.com:wenyu2026/echopath.git
cd echopath

# 2. 配置身份
git config --global user.name "你的GitHub用户名"
git config --global user.email "你的邮箱"

# 3. 装依赖
npm install

# 4. 配置环境变量（向队长要 API Key）
copy .env.example .env
```

**网络约束**：
- GitHub **必须走代理**：`git config --global http.https://github.com.proxy http://127.0.0.1:7890`
- TokenDance **不要走代理**（实测直连更快）

# 📋 Damn4lee —— T2+T3 AI/后端（P0 核心）

```
你是 4 人黑客松团队的 AI/后端负责人，负责核心技术链路。

【项目】来路 EchoPath —— 用 AI 帮你找到「和你走到过相似人生节点的人」
【你的 Issue】#14（检索链路）+ #15（反类比 + 证据分层）

【第一步】完整读这三个文件：
1. AGENTS.md —— 全队协作规则
2. .agent/DecisionEpisode-Schema.md —— 数据契约（含已验证的调用配置）
3. .agent/AI接入方案.md —— TokenDance 接入参数

【你的任务】
实现从「用户输入」到「返回 3 个案例」的完整链路。

【三个模块】
1. Situation Parser：用户自然语言 → 结构化 JSON
2. 向量召回：embedding + 余弦相似度
3. 结构重排 + 多样性选择

【🔴 已验证的配置，照抄即可】
· model: 'glm-5'
· reasoning_effort: 'none'     ← 不加会慢 3.7 倍（22.7s → 6.0s）
· response_format: { type: 'json_schema', json_schema: {...strict: true} }

【🚫 实测踩过的坑，别重踩】
· 别用 glm-5.3-flash —— content 为空，输出全跑 reasoning 里
· 别用 json_object —— 只保证语法，不保证符合 Schema
  （实测 risk 字段会返回长句子而不是 "medium"）
· 不需要向量库 —— 36-60 条数据直接内存算余弦相似度（<1ms）

【多样性硬要求】
最终 3 个案例的 choice.type 至少覆盖 2 种不同值。
（方案验收清单明确要求）

【#15 反类比 —— 产品最强记忆点】
主动输出「至少 2 个重要的不可比因素」。
聊天机器人永远不会主动说「你不能照搬」，这是差异化核心。

【#15 证据分层】
必须分层输出：facts / self_claims / interpretations / ai_inferences / unknowns
ai_inference 的内容绝不允许出现在 facts 层。

【硬规则】
· 分支用 Damn4lee/xxx
· 不许提交 package-lock.json、不许提交 .env
· API Key 从环境变量读，绝不硬编码

【开工前】
去 Issue #14 发 CHECKIN。数据（#13）没就绪时先用 3-5 条样例跑通，别等。

现在开始：先读 Schema，然后告诉我你的技术选型（Python FastAPI 还是 Node）。
```
